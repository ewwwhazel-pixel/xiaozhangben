小账本 APK 工程（嫩粉暖白配色）
================================
本工程已将记账界面改为柔和嫩粉色 + 暖白色：暖白背景、淡粉卡片、豆沙粉进度条与按钮、暖灰棕文字。

注意：这是 APK 工程源码 ZIP，不是 APK 安装包。需上传工程文件到 GitHub，并通过 Actions 自动构建 APK。
1. 解压 ZIP。
2. 在 GitHub 仓库中上传解压后的所有文件和文件夹（不是只上传 ZIP）。
3. 打开仓库的“操作（Actions）”，运行“Build Android APK”。
4. 构建成功后，在 Artifacts 下载 xiaozhangben-debug-apk，解压得到 app-debug.apk。
